# Week 2 Assignments

`Week2Assignments.java` implements all five problems from **STEP-SEM3-Week2-Assignment Problems.pdf**:

1. ATM PIN length validation with `length()`.
2. Per-word reversal with `split(" ")`, loops, and `StringBuilder`.
3. CSV inventory parsing with field-count validation.
4. ISBN-style code normalization and validation without regular expressions.
5. Stop-word-filtered word-frequency reporting sorted by descending count.

## Run

```text
javac Week2Assignments.java
java Week2Assignments
```

The `main` method runs the examples supplied by the assignment. Each problem is also exposed through a
separate method so the examples can be replaced with user input or unit tests.
